# Story

Hinglish fiction – Cuckold story (Bull / Wife / Husband).

Sab characters 18+.
No incest.

## Structure

- **1-Places** – Locations
- **2-Characters** – Wife, Husband, Bull
- **3-Scenes** – Story scenes
- **4-Chapters** – Ordered groups of scenes
- **Templates** – Reusable note templates

## Story Structure

Scenes are the building blocks of the story; each should advance, reveal, or change something. Chapters arrange scene notes in reading order using embeds. Give each note a unique, type-prefixed ID; replace template example IDs and links when creating notes.

## Writing Guidelines

- Write story narration, dialogue, and character/place descriptions in Hinglish: use Roman script for Hindi and mix in English naturally.
- Headings, filenames, metadata labels, and organizational documentation may remain in English.
